# run project

Step-A1 : To run the app  , cal this command in terminal => npx gulp start


To change the project template :
Step-B1: To change the index.html according to the template given
Step-B2: To change the theme.css file path in index.html, ./theme/theme.css => ./output/theme.css
Step-B3: To change the foldername in /app/scss/theme.scss

Once changed the project folder name in theme.scss, like this
Eg: template folder/specific project folder/*
@import './priips_kid_base/morgan_stanley/_addon.scss';

Step-B4: if the project is throwing error.Then please rerun the project using above command in Step-A1.


Note : Different project templates ubs_kid_base/prps_monthperf/prps_pastperf/priips_kid_base
Add the images and fonts inside \dist\output\images\* 

Step-C1: Once finished development , download the dist\theme.css and create a new theme in theme manager
Step-C2: Copy all the project related fonts and images from (\dist\output\images\* ) , while creating theme in theme manager
