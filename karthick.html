    1. Hardware

    • Hardware refers to the physical components of a computer system that you can touch.

    • It includes input devices (keyboard, mouse), output devices (monitor, printer), storage devices (HDD, SSD), and processing units (CPU, GPU).

    • Hardware works in conjunction with software to perform tasks and run programs.

    • Types of hardware include internal (motherboard, RAM, processor) and external (USB devices, printers).

    • Proper hardware is crucial for performance, speed, and reliability of a computer system.

    2. Computer Network

    • A computer network is a system of interconnected computers that communicate and share resources.

    • Networks can be LAN (Local Area Network), WAN (Wide Area Network), MAN (Metropolitan Area Network).

    • Networks enable sharing of files, printers, internet connections, and other resources.

    • Components include routers, switches, hubs, and network cables.

    • Network security protocols are essential to protect data from unauthorized access.

    3. Hub

    • A hub is a basic networking device that connects multiple devices in a LAN.

    • It operates at the Physical Layer (Layer 1) of the OSI model.

    • Hub broadcasts incoming data packets to all ports, causing more network traffic.

    • It has no intelligence; it does not filter or route data.

    • Hubs are largely replaced by switches due to inefficiency and collisions.

    4. Switch

    • A switch is a network device that connects multiple devices in a LAN.

    • Operates at Data Link Layer (Layer 2) and sometimes Layer 3 for routing.

    • It sends data only to the device for which it is intended, reducing collisions.

    • Switches maintain a MAC address table to forward packets efficiently.

    • Common in modern networks because it improves speed and security compared to hubs.

    5. Router

    • A router is a device that forwards data packets between different networks.

    • Operates at the Network Layer (Layer 3) of the OSI model.

    • Determines the best path for data to reach its destination using routing tables.

    • Routers connect LANs to WANs (like connecting a home network to the Internet).

    • Can provide additional features like DHCP, NAT, and firewall functionality.

    6. Protocol

    • Protocols are standardized rules that allow computers to communicate over a network.

    • They define how data is transmitted, received, and interpreted.

    • Examples include HTTP, FTP, TCP/IP, UDP, SMTP.

    • Protocols ensure data integrity, proper sequencing, and error handling.

    • Without protocols, devices would not understand each other’s data.

    7. TCP (Transmission Control Protocol)

    • TCP is a connection-oriented protocol that ensures reliable communication.

    • It divides data into packets and reassembles them at the destination.

    • Provides error checking and retransmission of lost packets.

    • Operates at the Transport Layer of the OSI model.

    • Commonly used for web browsing (HTTP), email (SMTP), and file transfers (FTP).

    8. UDP (User Datagram Protocol)

    • UDP is a connectionless protocol used for fast, low-latency transmission.

    • It does not guarantee packet delivery, order, or error correction.

    • Ideal for real-time applications like video streaming, gaming, and VoIP.

    • Less overhead than TCP, so it is faster but less reliable.

    • Operates at the Transport Layer alongside TCP.

    9. Firewall

    • A firewall is a security system that monitors and controls incoming/outgoing network traffic.

    • It can be hardware-based, software-based, or both.

    • Firewalls filter traffic based on rules like IP address, port number, and protocol.

    • Protects against unauthorized access, malware, and network attacks.

    • Examples include Windows Defender Firewall, Cisco ASA, and pfSense.

    10. DNS (Domain Name System)

    • DNS translates human-readable domain names (like www.google.com) into IP addresses.

    • Operates at the Application Layer of the OSI model.

    • Without DNS, users would need to remember numeric IP addresses for websites.

    • DNS servers can be recursive, authoritative, or caching types.

    • It is essential for web browsing, email routing, and many network services.

    11. 3-Tier Network Architecture

    Layers: Core, Distribution, Access

    Layer Purpose Key Devices
    Core Layer High-speed backbone, handles large data traffic Routers, Core Switches
    Distribution Layer Policy control, routing, filtering, and QoS Layer 3 Switches
    Access Layer Connect end devices (PC, printer, etc.) Switches, Hubs

    • Core: Fast forwarding of packets, connects different sites.

    • Distribution: Aggregates access layer data and applies policies.

    • Access: Directly connects users and endpoints to the network.

    12. Types of Communication

    • Unicast: One-to-one communication where a single sender transmits data to a single receiver. Example: Sending an email.

    • Broadcast: One-to-all communication where data is sent to all devices in a network segment. Example: ARP requests in LAN.

    • Multicast: One-to-many communication where data is sent to a specific group of devices. Example: IPTV streaming.

    • Anycast: One-to-nearest communication where data is delivered to the nearest or best node in a group. Example: DNS query responses.

    • Each type optimizes network resources depending on the data distribution requirements.

    13. Types of Ports

    • Physical Ports: Hardware interfaces on devices, like USB, Ethernet (RJ-45), HDMI, and Serial ports.

    • Logical/Network Ports: Numbered endpoints for network communication, ranging from 0 to 65535.

    • Common Ports: HTTP – 80, HTTPS – 443, FTP – 21, SMTP – 25, DNS – 53.

    • Ports allow multiple applications to use a single network interface without conflict.

    • Proper port management ensures secure and efficient network communication.

    14. Types of Memory

    Type Description
    Volatile Requires power to retain data. Example: RAM. Data is lost when power is off.
    Non-volatile Retains data even when power is off. Example: ROM, Flash memory.
    ROM Read-Only Memory, preloaded with firmware, cannot be easily modified.
    RAM Random Access Memory, used for temporary storage during operations.
    Flash Memory Non-volatile memory, rewritable, used in SSDs, USB drives, smartphones.

    • Memory types differ in speed, cost, and purpose within a computer system.

    15. OSI Layer (7 Layers)

    Layer Function
    1. Physical Transmission of raw bits over physical media. Devices: Hub, Cables.
    2. Data Link Error detection, MAC addressing, frames. Devices: Switch, Bridge.
    3. Network Routing and logical addressing (IP). Device: Router.
    4. Transport Reliable data transfer, flow control, segmentation.
    5. Session Manages sessions between applications, e.g., login sessions.
    6. Presentation Data translation, encryption, compression, formatting.
    7. Application Provides network services to end-users, e.g., HTTP, FTP, DNS.

    • Each layer has a specific function that ensures smooth communication from source to destination.

    16. TCP/IP

    • TCP/IP is a suite of communication protocols used for the Internet and private networks.

    • Consists of 4 layers: Link, Internet, Transport, Application.

    • TCP ensures reliable delivery; IP handles addressing and routing.

    • Other protocols: UDP, ICMP, HTTP, FTP, SMTP.

    • TCP/IP allows heterogeneous networks to interconnect and communicate seamlessly.

    17. Topology & Types

    • Topology: The physical or logical arrangement of network devices.

    Type Description
    Bus Single backbone cable, all devices connected. Easy to set up, but fault-prone.
    Star Devices connected to a central hub/switch. Reliable, easy troubleshooting.
    Ring Devices connected in a circular manner. Data flows in one direction.
    Mesh Devices interconnected with multiple paths. Very reliable but expensive.
    Tree Hierarchical combination of star and bus topologies.
    Hybrid Combination of two or more topologies for flexibility.

    18. Types of Passwords

    • Alphanumeric: Contains letters and numbers. Example: Hema1234.

    • Complex/Special Character: Includes symbols, numbers, and letters. Example: H3m@2026.

    • Passphrases: Longer phrases that are easy to remember but strong. Example: “MyBabyDueInMarch2026!”

    • One-Time Passwords (OTP): Temporary password valid for a single login/session.

    • Biometric Passwords: Uses fingerprint, face, or iris for authentication.

    • Strong passwords prevent unauthorized access and improve security.

    19. Remote Control Authentication Protocol & Types

    • Protocols allow secure access to network devices from remote locations.

    • Types:

      • RDP (Remote Desktop Protocol): Windows remote access.

      • Telnet: Older remote access, unencrypted (not secure).

      • SSH (Secure Shell): Encrypted remote access for Linux/Unix devices.

      • VPN (Virtual Private Network): Secure network tunneling for remote access.

    • Proper authentication ensures only authorized users can control devices remotely.

    20. Telnet

    • Telnet is a network protocol used to access devices remotely.

    • Operates over TCP, typically port 23.

    • Provides command-line access to network devices like routers and switches.

    • Sends data in plain text, making it insecure for sensitive systems.

    • Mostly replaced by SSH due to security vulnerabilities.

    21. SSH (Secure Shell)

    • SSH is a secure replacement for Telnet.

    • Provides encrypted communication over an insecure network.

    • Operates on TCP port 22.

    • Allows remote login, command execution, and file transfer.

    • Widely used in Linux/Unix administration for security and reliability.

    22. Routing & Types

    • Routing is the process of selecting paths in a network for sending data packets.

    • Routers use routing tables and protocols to determine the best path for data.

    • Types of Routing:

      1. Static Routing:

        • Static routing means routes are manually configured by the network administrator.

        • The router does not change the path automatically when the network changes.

        • It is simple, secure, and uses less CPU and memory.

        • Best suited for small networks with few routes.

        • If a link fails, the admin must manually fix the route.

      2. Dynamic Routing:

        • Dynamic routing uses routing protocols to learn and update routes automatically.

        • Routers share routing information with each other.

        • It adapts automatically when the network topology changes.

        • Used in large and complex networks.

        • Examples: RIP, OSPF, EIGRP, BGP.

      3. Default Routing:

        • Default routing uses a single route to send all unknown traffic.

        • It is used when no specific route matches the destination.

        • Commonly used in small networks and edge routers.

        • Simplifies routing table configuration.

        • Usually points to the ISP router or main gateway.

    • Proper routing ensures efficient, fast, and reliable communication across networks.

    23. RIP (Routing Information Protocol)

    • RIP is a dynamic routing protocol used in small networks.

    • Uses hop count as a metric to determine the best path; max 15 hops allowed.

    • Routers periodically share routing tables every 30 seconds.

    • Simple to configure but not suitable for large networks due to slow convergence.

    • Operates using UDP port 520.

    24. EIGRP (Enhanced Interior Gateway Routing Protocol)

    • EIGRP is an advanced Cisco proprietary routing protocol.

    • Uses a combination of bandwidth, delay, load, and reliability as metrics.

    • Supports faster convergence and loop-free paths using Diffusing Update Algorithm (DUAL).

    • Works for both IPv4 and IPv6 networks.

    • Preferred in medium to large enterprise networks due to efficiency.

    25. OSPF (Open Shortest Path First)

    • OSPF is a widely used link-state routing protocol.

    • Uses Dijkstra’s algorithm to calculate the shortest path tree.

    • Sends updates only when network topology changes, saving bandwidth.

    • Suitable for large, hierarchical networks with multiple routers.

    • Operates using IP protocol 89.

    26. BGP (Border Gateway Protocol)

    • BGP is an inter-domain routing protocol used on the Internet.

    • Known as the “protocol of the Internet” for connecting Autonomous Systems (AS).

    • Uses path vector protocol to determine best routes.

    • Supports policy-based routing and loop prevention.

    • Operates over TCP port 179, making it reliable for global routing.

    27. Straight Cable

    • Used to connect different devices like a computer to a switch/router.

    • Pins are wired 1:1 (Pin 1 → Pin 1, Pin 2 → Pin 2, etc.).

    • Common for LAN connections to networking devices.

    • Supports fast Ethernet speeds efficiently.

    • Not used for connecting similar devices (like switch-to-switch).

    28. Crossover Cable

    • Used to connect similar devices, like switch-to-switch or computer-to-computer.

    • Transmit and receive pairs are swapped (Pin 1 ↔ Pin 3, Pin 2 ↔ Pin 6).

    • Allows devices to communicate directly without an intermediary device.

    • Ideal for testing and peer-to-peer connections.

    • Can also be replaced by Auto-MDI/MDIX-enabled ports on modern switches.

    29. Rollover Cable

    • Used primarily to connect a PC to a router or switch console port.

    • Pins are reversed (Pin 1 ↔ Pin 8, Pin 2 ↔ Pin 7, etc.).

    • Also called a Cisco console cable.

    • Allows device configuration using terminal software like PuTTY or HyperTerminal.

    • Not used for general network traffic; only for management purposes.

    30. DHCP (Dynamic Host Configuration Protocol)

    • DHCP automatically assigns IP addresses and other network configuration to devices.

    • Operates using UDP ports 67 (server) and 68 (client).

    • Reduces manual configuration errors and simplifies network management.

    • Can provide IP address lease times, DNS server, gateway info, and more.

    • Essential for large networks with frequently changing devices.

    31. What is NAT (Network Address Translation)?

    • NAT is a method used in routers to translate private IP addresses into public IP addresses and vice versa.

    • It allows many devices in a local network (LAN) to use one public IP to access the Internet.

    • NAT helps in saving IPv4 addresses, because public IPs are limited.

    • It also adds a layer of security by hiding internal IP addresses from the outside world.

    • NAT works mainly at the Network Layer (Layer 3) of the OSI model.

    32. Main Types of NAT?

    1️⃣ Static NAT

    • Maps one private IP to one public IP permanently.

    • The mapping never changes.

    • Used when a server inside the LAN must always be reachable from the Internet.

    • Example: A web server with fixed public IP.

    • Not suitable for large networks because it needs many public IPs.

    2️⃣ Dynamic NAT

    • Maps private IPs to a pool of public IPs dynamically.

    • When a device accesses the Internet, it gets a public IP temporarily.

    • Once the session ends, the IP goes back to the pool.

    • Saves public IPs compared to Static NAT.

    • Still limited by the number of public IPs in the pool.

    3️⃣ PAT (Port Address Translation) / NAT Overload

    • Many private IPs use one single public IP with different port numbers.

    • Most common type of NAT used in homes and offices.

    • Router tracks connections using IP + Port number.

    • Allows thousands of devices to share one public IP.

    • Also called NAT Overloading.

    37) NTP (Network Time Protocol)

    Definition:
    NTP synchronizes time between computers in network.

    Explanation (5 Points):

    1. Uses UDP port 123.

    2. Maintains accurate time.

    3. Used in servers and routers.

    4. Prevents time mismatch errors.

    5. Critical for logs and security.

    38) Reference Clock

    Definition:
    Reference clock is the original time source for NTP.

    Explanation (5 Points):

    1. Connected to atomic clock or GPS.

    2. Provides most accurate time.

    3. Used in Stratum 0.

    4. Not directly connected to clients.

    5. Sends time to primary servers.

    39) NTP Hierarchy

    Explanation (5 Points):

    1. Organized in Stratum levels.

    2. Stratum 0 – Atomic clock.

    3. Stratum 1 – Primary server.

    4. Stratum 2 – Secondary server.

    5. Lower stratum number = Higher accuracy.

    40) Primary Server

    Explanation (5 Points):

    1. Connected to Stratum 0.

    2. Also called Stratum 1.

    3. Provides time to secondary servers.

    4. Highly accurate.

    5. Used in data centers.

    41) Secondary Server

    Explanation (5 Points):

    1. Gets time from primary server.

    2. Called Stratum 2.

    3. Distributes time to clients.

    4. Less accurate than primary.

    5. Reduces load on primary server.
