  8. What is the "this" keyword in JavaScript?

    In JavaScript, the this keyword refers to the object that is currently executing the code. The value of this depends on how and where the function is invoked, making it a dynamic context.

    Here's a breakdown of how this works in different contexts:

    1. Global Context:
      When used in the global scope, this refers to the global object (window in browsers, global in Node.js).

      javascript
      console.log(this); // In a browser, this will log the window object.

    2. Object Method:
      When a function is called as a method of an object, this refers to the object that is calling the method.

      javascript
      const obj = {
    name: "Petchi",
    greet: function() {
        console.log(this.name);
    }
};
obj.greet(); // "Petchi" - this refers to obj

    3. Constructor Functions:
      In a constructor function (using the new keyword), this refers to the new object being created.

      javascript
      function Person(name) {
    this.name = name;
}
const person = new Person("Petchi");
console.log(person.name); // "Petchi"

    4. Event Handlers:
      In an event handler, this refers to the element that received the event.

      javascript
      const button = document.querySelector("button");
button.addEventListener("click", function() {
    console.log(this); // this refers to the button element
});

    5. Arrow Functions:
      Arrow functions do not have their own this context. Instead, they inherit this from the enclosing lexical context (the surrounding non-arrow function or global scope).

      javascript
      const obj = {
    name: "Petchi",
    greet: function() {
        const arrowFunc = () => {
            console.log(this.name);
        };
        arrowFunc(); // "Petchi" - this refers to obj
    }
};
obj.greet();

    Understanding the this keyword is crucial for working with object-oriented programming in JavaScript, as it helps determine the context in which a function is executed.

function isArmstrong(num) {
    var sum = 0;
    var numStr = num.toString();
    
    for (var i = 0; i < numStr.length; i++) {

  39. Call,bind, apply javascript in JS?

    In JavaScript, call, bind, and apply are methods used to manipulate the this keyword within functions and to control how functions are executed.

    1. call Method: The call method is used to invoke a function with a specified this value and arguments provided individually. 

      javascript
      function greet(name) {
                console.log(`Hello, ${name}! I'm ${this.name}.`);
            }
            
            const person = { name: 'John' };
            
            greet.call(person, 'Alice'); // Output: Hello, Alice! I'm John.

    2. bind Method: The bind method creates a new function that, when called, has its this keyword set to a specific value, and with any number of specified arguments preceding any provided when the new function is called.

      
                
      javascript
      function greet(name) {
                console.log(`Hello, ${name}! I'm ${this.name}.`);
            }
            
            const person = { name: 'John' };
            const greetPerson = greet.bind(person);
            
            greetPerson('Alice'); // Output: Hello, Alice! I'm John.

    3. apply Method: The apply method is similar to call, but it accepts arguments as an array.

      javascript
      function greet(name1, name2) {
                console.log(`Hello, ${name1} and ${name2}! I'm ${this.name}.`);
            }
            
            const person = { name: 'John' };
            
            greet.apply(person, ['Alice', 'Bob']); // Output: Hello, Alice and Bob! I'm John.

    All three methods are primarily used to control the context (this value) of a function when it's executed. call and apply immediately invoke the function, while bind returns a new function with the specified context and arguments, which can be called later.

  41. What is the difference between shift and unshift method of arrays?

    In JavaScript, shift and unshift are methods used to manipulate the elements of an array, but they do so in opposite ways:

    • shift(): Removes the first element from an array and returns that removed element. This method also changes the length of the array.

      javascript
      let array = [1, 2, 3];
                    let removedElement = array.shift();
                    console.log(removedElement); // Output: 1
                    console.log(array); // Output: [2, 3]

    • unshift(): Adds one or more elements to the beginning of an array and returns the new length of the array.

      javascript
      let array = [1, 2, 3];
                    let newLength = array.unshift(0);
                    console.log(newLength); // Output: 4
                    console.log(array); // Output: [0, 1, 2, 3]

    So, shift is used to remove elements from the start of an array, while unshift is used to add elements to the start of an array.

  43. Write a Javascript program where you will pass a string, and that string should return all the possible word counts.

    Here’s a JavaScript program that takes a string as input and returns a count of all the words in that string:

    javascript
    function wordCount(str) {
// Convert the string to lowercase and split it into words
let words = str.toLowerCase().match(/\b\w+\b/g);

// Create an object to hold the word counts
let wordCounts = {};

// Iterate over the words and count their occurrences
words.forEach(word => {
    if (wordCounts[word]) {
        wordCounts[word]++;
    } else {
        wordCounts[word] = 1;
    }
});

return wordCounts;
}

// Example usage:
let inputString = "Hello world! Hello everyone. Welcome to the world of JavaScript.";
let result = wordCount(inputString);
console.log(result);

    Explanation:

    1. Convert to Lowercase: The string is converted to lowercase using str.toLowerCase() to ensure that the counting is case-insensitive.
    2. Split String into Words: The match(/\b\w+\b/g) method splits the string into words using a regular expression, which matches word boundaries (\b) and word characters (\w).
    3. Count Occurrences: The program iterates through the words array, counting the occurrences of each word and storing the count in the wordCounts object.

    Example Output:

  44. wht is class in JS?

    In JavaScript (JS), a class is a blueprint for creating objects. It defines the properties and methods that the created objects will have. Classes in JavaScript are part of the ECMAScript 6 (ES6) standard and provide a more structured and object-oriented way to create and manage objects.

    Key Concepts of Classes in JavaScript:

    1. Class Declaration:

      • A class is defined using the class keyword.
      • Inside a class, you define a constructor method and other methods.
      javascript
      class Person {
    constructor(name, age) {
        this.name = name;
        this.age = age;
    }

    greet() {
        console.log(`Hello, my name is ${this.name} and I am ${this.age} years old.`);
    }
}

    2. Constructor:

      • The constructor method is a special method for creating and initializing objects created with a class.
      • It is called automatically when a new instance of the class is created using the new keyword.
      javascript
      const person1 = new Person('John', 30);

    3. Methods:

      • Methods are functions defined inside a class. They operate on instances of the class.
      • In the example above, greet is a method that belongs to the Person class.
      javascript
      person1.greet();  // Output: Hello, my name is John and I am 30 years old.

    4. Inheritance:

      • Classes can inherit from other classes using the extends keyword.
      • The super keyword is used to call the constructor of the parent class.
      javascript
      class Employee extends Person {
    constructor(name, age, jobTitle) {
        super(name, age);
        this.jobTitle = jobTitle;
    }

    describeJob() {
        console.log(`I am a ${this.jobTitle}.`);
    }
}
