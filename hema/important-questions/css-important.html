  3. How do you select elements in CSS

    In CSS, you can select elements using selectors.

    1. Element selectors: Element selectors select elements based on their tag name. For example, p selects all p elements on the page.

    Example:

    p {
    color: red;
}
    1. Class selectors: Class selectors select elements based on the value of their class attribute. To create a class selector, use a period (.) followed by the class name.

    Example:

    .highlight {
    background-color: yellow;
}
    1. ID selectors: ID selectors select elements based on the value of their id attribute. To create an ID selector, use a hash (#) followed by the ID name.

    Example:

    #header {
    font-size: 24px;
}
    1. Attribute selectors: Attribute selectors select elements based on the value of their attributes. To create an attribute selector, use square brackets ([attribute=value]).

    Example:

    input[type="text"] {
    border: 1px solid black;
}
    1. Combination selectors: Combination selectors select elements based on a combination of selectors. For example, p.highlight selects all p elements with the class name highlight.

    Example:

    p.highlight {
    color: blue;
}

    Padding is the space between an element's content and its border. It affects the size of the element's content area, but not its overall size.

    Margin, on the other hand, is the space outside an element's border, between the element and other elements on the page. It affects the layout of the element on the page, but not the size of the element's content area.

  6. CSS Flexbox?

    CSS Flexbox is a layout model used to create flexible and responsive layouts for web pages.

    flex-direction: The direction in which the flex items are laid out in the flex container.

    justify-content: Determines how the flex items are distributed along the main axis.

    align-items: Determines how the flex items are aligned along the cross axis.

    align content: Determines how the rows are aligned along the cross axis.

    • flex-start: The default value, aligns flex items to the start of the container.
    • flex-end: Aligns flex items to the end of the container.
    • center: Centers the flex items within the container.
    • space-between: Distributes the flex items evenly along the main axis with space between the items.
    • space-around: Distributes the flex items evenly along the main axis with space around the items.
    • space-evenly: Distributes the flex items evenly along the main axis with equal space between and around the items.

  7. What are the different units of measurement in CSS?

    1. Pixels (px): A pixel is a unit of measurement that is relative to the resolution of the screen or device. It is a fixed size, and one pixel is equal to one dot on a screen.
    2. Percentages (%): Percentages are relative units of measurement that are based on the size of the element's parent. For example, setting width: 50%; on an element would make it half the width of its parent.
    3. Em (em): An em is a unit of measurement that is relative to the font size of the element. One em is equal to the font size of the element, so setting font-size: 2em; would make the text twice as large as the default font size.
    4. Rem (rem): A rem is similar to an em, but it is relative to the root element's font size (usually the html element). This makes it more predictable than em units, which can be affected by nested elements.
    5. Viewport units (vw, vh, vmin, vmax): Viewport units are relative to the size of the viewport (i.e., the browser window). 1vw is equal to 1% of the viewport width, 1vh is equal to 1% of the viewport height, 1vmin is equal to the smaller of the two, and 1vmax is equal to the larger of the two.
    6. Absolute units (in, cm, mm, pt, pc): Absolute units are fixed units of measurement that are not relative to anything else. For example, 1in is equal to one inch, 1cm is equal to one centimeter, 1mm is equal to one millimeter, 1pt is equal to 1/72 of an inch, and 1pc is equal to 12 points.

  8. How do you center an element horizontally and vertically in CSS flex?

    In CSS flexbox, we can center an element both horizontally and vertically by using the display: flex and align-items:center and justify-content:center properties.

    .container {
    display: flex;
    align-items: center; /* Center vertically */
    justify-content: center; /* Center horizontally */
}

  9. What is a CSS pseudo-class and give an example?

    A pseudo-class is used to define a special state of an element.

    1. :hover - apply a style when the link is being hovered over by the mouse.

      Example:

      
a:hover {
    color: red;
}
    2. :active - applies a style when the element is being clicked.

      Example:

      
a:active {
    color: green;
}
    3. :focus - applies a style when the element has focus (i.e., is currently selected)

      Example:

      
a:focus {
    color: yellow;
}
    4. :first-child - applies a style to the first child element of the parent element

      Example:

      
a:first-child {
    color: orange;
}
    5. :last-child - applies a style to the first child element of the parent element.

      Example:

      
a:last-child {
    color: pink;
}
    6. :nth-child() - applies a style to an element that is the nth child of its parent element, where n is a number or formula.

      Example:

      
a:last-child {
    color: pink;
}

  11. What is the difference between display: none and visibility: hidden in CSS?

    display: none removes the element from the normal flow of the document and hides it completely. This means that the element takes up no space on the page and cannot be interacted withdisplay: none, it is as if the element doesn't exist at all.

    visibility: hidden hides the element from view but still takes up space on the page. This means that the layout of the page is not affected.

  12. What is the difference between position:relative , absolute, fixed, sticky , static?

    • position: static - HTML elements are positioned static by default.Element is positioned in the normal flow of the document, with no special positioning like we cant assigned top,left,right,bottom values.
    • position: relative - Element is positioned relative to its normal position in the document flow.We can assign special posiion values like top,left,right,bottom values.
    • position: absolute - Element is positioned relative to its first nearest positioned ancestor element, or the initial containing block if no positioned ancestor exists.
    • position: fixed - Element is positioned relative to the viewport, and stays in the same position even if the page is scrolled.
    • position: sticky - Element is positioned like position: relative until a certain point, at which point it becomes position: fixed.

  13. Naming convention and give an example?

    • Naming convention: A class is denoted with a period (.) followed by the class name, while an ID is denoted with a hash (#) followed by the ID name. For example: 
      .my-class {
    /* Styles for elements with the class "my-class" */
}
#my-id {
    /* Styles for the element with the ID "my-id" */
}
    • Usage: A class can be used multiple times in a single HTML document, while an ID must be unique within the document.
    • Specificity: In terms of CSS specificity, an ID has a higher specificity than a class. This means that styles applied with an ID selector will override styles applied with a class selector.
