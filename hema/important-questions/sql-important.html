1. What is SQL?

    • SQL stands for Structured Query Language. It's a standard language used for managing and manipulating relational databases.

  2. Differentiate between SQL and MySQL.

    • SQL is a language used to operate databases, while MySQL is one of several software applications that use SQL as its standard language.

  3. What are the different types of SQL statements?

    • SQL statements can be categorized into Data Definition Language (DDL), Data Manipulation Language (DML), Data Control Language (DCL), and Transaction Control Language (TCL).

  4. Explain the SELECT statement in SQL.

    • SELECT statement is used to retrieve data from a database. It allows you to specify which columns you want to retrieve and which table(s) to retrieve them from. 
      sql
      SELECT column1, column2 FROM table_name;

  5. What is a primary key?

    • A primary key is a unique identifier for a record in a table. It must contain unique values and cannot be NULL. 
      sql
      CREATE TABLE table_name (
    column1 datatype PRIMARY KEY,
    column2 datatype,
    ...
);

  6. What is a foreign key?

    • A foreign key is a column or group of columns in a relational database table that provides a link between data in two tables. It establishes a relationship between two tables by referencing the primary key of another table. 
      sql
      CREATE TABLE table_name (
    column1 datatype,
    column2 datatype,
    ...
    FOREIGN KEY (column1) REFERENCES other_table(column1)
);

  7. Explain the difference between DELETE and TRUNCATE commands.

    • DELETE command is used to remove rows from a table based on a condition, while TRUNCATE command is used to remove all rows from a table. 
      sql
      DELETE FROM table_name WHERE condition;
TRUNCATE TABLE table_name;

  8. What is a JOIN in SQL?

    • JOIN is used to combine rows from two or more tables based on a related column between them. 
      sql
      SELECT column_name(s)
FROM table1
JOIN table2 ON table1.column_name = table2.column_name;

  9. Differentiate between INNER JOIN and OUTER JOIN.

    • INNER JOIN returns only the rows where there is a match in both tables, while OUTER JOIN returns all rows from both tables, with NULL values where there is no match. 
      sql
      SELECT column_name(s)
FROM table1
INNER JOIN table2 ON table1.column_name = table2.column_name;

SELECT column_name(s)
FROM table1
LEFT JOIN table2 ON table1.column_name = table2.column_name;

  10. Explain the ACID properties in SQL.

    • ACID stands for Atomicity, Consistency, Isolation, and Durability. These properties ensure that database transactions are processed reliably.

  11. What is normalization in SQL?

    • Normalization is the process of organizing data in a database to reduce redundancy and dependency.

  12. What is denormalization?

    • Denormalization is the process of adding redundant data to a normalized database to improve read performance.

  13. Explain the difference between CHAR and VARCHAR data types.

    • CHAR is a fixed-length character data type, while VARCHAR is a variable-length character data type.

  14. What is a subquery?

    • A subquery is a query nested within another query. It can be used to return data that will be used in the main query as a condition.

  15. What is a view in SQL?

    • A view is a virtual table based on the result of a SELECT query. It allows users to access and manipulate data without altering the underlying database tables.
    sql
    CREATE VIEW view_name AS
SELECT column1, column2
FROM table_name
WHERE condition;

  16. What is the difference between UNION and UNION ALL?

    • UNION combines the results of two or more SELECT statements and removes duplicate rows, while UNION ALL does not remove duplicates.
    sql
    SELECT column1 FROM table1
UNION
SELECT column1 FROM table2;

SELECT column1 FROM table1
UNION ALL
SELECT column1 FROM table2;

  17. Explain the HAVING clause.

    • The HAVING clause is used in combination with the GROUP BY clause to filter the results of aggregate functions.
    sql
    SELECT column1, COUNT(column2)
FROM table_name
GROUP BY column1
HAVING COUNT(column2) > 10;

  18. What is the difference between WHERE and HAVING clauses?

    • WHERE clause is used to filter rows before any grouping is done, while HAVING clause is used to filter rows after the grouping has occurred.

  19. What is a stored procedure?

    • A stored procedure is a prepared SQL code that you can save, so the code can be reused over and over again.
    sql
    CREATE PROCEDURE procedure_name
AS
SQL_statements;

  20. Explain the difference between a stored procedure and a function.

    • A stored procedure can perform a series of SQL statements, while a function returns only a single value.

  21. What is a trigger?

    • A trigger is a set of SQL statements that automatically "fires" or executes when a certain event occurs in a database.
    sql
    CREATE TRIGGER trigger_name
AFTER INSERT ON table_name
FOR EACH ROW
BEGIN
    -- Trigger logic here
END;

  22. What is the difference between a clustered and a non-clustered index?

    • A clustered index determines the physical order of data in a table, while a non-clustered index does not.

  23. Explain the difference between a candidate key, a primary key, and a unique key.

    • A candidate key is any column or combination of columns that can uniquely identify a record, a primary key is the candidate key chosen by the database designer as the main method of uniquely identifying records, and a unique key is any candidate key that has been designated as unique.

  24. What is the difference between TRUNCATE and DROP statements?

    • TRUNCATE removes all records from a table, but the table structure and its columns, constraints, indexes, and so on remain. DROP removes the table from the database entirely.

  25. What is a self-join?

    • A self-join is a regular join but with a table joining to itself.
    sql
    SELECT e1.employee_id, e1.employee_name, e2.manager_name
FROM employees e1
JOIN employees e2 ON e1.manager_id = e2.employee_id;

  26. Explain the concept of a transaction in SQL.

    • A transaction is a sequence of one or more SQL statements that are treated as a single unit of work, which either fully completes or is fully rolled back.
    sql
    BEGIN TRANSACTION;
-- SQL statements
COMMIT;

  27. What is a correlated subquery?

    • A correlated subquery is a subquery that uses values from the outer query.

  28. Explain the use of the COALESCE function.

    • The COALESCE function returns the first non-null value in a list of expressions.
    sql
    SELECT COALESCE(column1, column2, 'default_value') AS alias_name
FROM table_name;

  29. What is the difference between the ROLLBACK and COMMIT commands?

    • ROLLBACK undoes transactions that have not been saved to the database, while COMMIT saves all changes to the database.

  30. What are constraints in SQL?

    • Constraints are rules enforced on data columns to ensure the accuracy and reliability of data in the database.
    sql
    CREATE TABLE table_name (
    column1 datatype CONSTRAINT constraint_name,
    column2 datatype,
    ...
);

  31. Explain the GROUP BY clause.

    • The GROUP BY clause is used to group rows that have the same values into summary rows, such as "find the number of customers in each city."
    sql
    SELECT column1, COUNT(*)
FROM table_name
GROUP BY column1;

  32. What is the purpose of the CASE statement?

    • The CASE statement is used to create different outputs (usually in the SELECT statement) based on certain conditions.
    sql
    SELECT column1,
       CASE
           WHEN condition1 THEN 'value1'
           WHEN condition2 THEN 'value2'
           ELSE 'default_value'
       END AS alias_name
FROM table_name;

  33. What is a cursor in SQL?

    • A cursor is a database object used to retrieve and manipulate data row by row.
    sql
    DECLARE cursor_name CURSOR FOR
SELECT column1 FROM table_name;
OPEN cursor_name;
FETCH NEXT FROM cursor_name INTO @variable;
CLOSE cursor_name;

  34. Explain the purpose of the ROW_NUMBER() function.

    • The ROW_NUMBER() function assigns a unique number to each row to which it is applied, typically ordered by some criteria.
    sql
    SELECT column1, ROW_NUMBER() OVER (ORDER BY column1) AS row_num
FROM table_name;

  35. What is a recursive query?

    • A recursive query is a query in which a CTE (Common Table Expression) references itself.
    sql
    WITH RECURSIVE cte_name AS (
    -- Anchor member
    SELECT ...
    UNION ALL
    -- Recursive member
    SELECT ...
    FROM cte_name
    WHERE condition
)
SELECT * FROM cte_name;

  36. Explain the concept of database normalization.

    • Database normalization is the process of organizing the attributes and tables of a relational database to minimize redundancy and dependency.

  37. What is the difference between a trigger and a stored procedure?

    • A trigger is automatically executed or fired when a specified event occurs, while a stored procedure must be explicitly executed.

  38. What is a Cartesian join?

    • A Cartesian join (also known as a cross join) is a join operation that produces the Cartesian product of two tables.
    sql
    SELECT *
FROM table1
CROSS JOIN table2;

  39. What is the purpose of the INDEX command?

    • INDEX command is used to create indexes on tables, which can improve query performance by allowing the database engine to quickly locate rows in the table.
    sql
    CREATE INDEX index_name ON table_name (column1, column2);

  40. Explain the difference between the WHERE and HAVING clauses in SQL.

    • WHERE clause is used to filter rows before any grouping is done, while HAVING clause is used to filter rows after the grouping has occurred.
