1. What is C#?

    C# (pronounced as C sharp) is an object-oriented programming language developed by Microsoft within its .NET framework for building a variety of applications.

  2. What is .NET Framework?

    .NET Framework is a software development platform developed by Microsoft that consists of a large class library and provides language interoperability across several programming languages. It provides tools and libraries for building different types of applications.

  3. What is the difference between String and StringBuilder in C#?

    String is immutable, meaning its value cannot be changed once it's created, while StringBuilder is mutable, allowing for dynamic modification of its content.

    Example:

    csharp
    string str = "Hello";
str += " World"; // This creates a new string object
StringBuilder sb = new StringBuilder("Hello");
sb.Append(" World"); // This modifies the existing StringBuilder object

  4. What is the difference between Abstract Class and Interface?

    Abstract classes can contain method implementations while interfaces cannot. A class can implement multiple interfaces but can inherit only one abstract class.

  5. Explain Polymorphism in C#.

    Polymorphism allows methods to do different things based on the object that it is acting upon. This can be achieved through method overriding and method overloading.

  6. What is the difference between Ref and Out keywords in C#?

    Both ref and out keywords are used for passing arguments by reference, but the out parameter does not require the variable to be initialized before being passed as an argument.

    Example:

    csharp
    void GetValue(ref int x)
{
    x = 10;
}

void GetNumber(out int y)
{
    y = 20;
}

  7. What are the different types of access modifiers in C#?

    The access modifiers in C# are public, private, protected, internal, and protected internal.

  8. What is a Delegate in C#?

    A delegate is a type that represents references to methods with a specific signature. It is similar to a function pointer in C++.

    Example:

    csharp
    public delegate void MyDelegate(string message);

class Program
{
    static void Main(string[] args)
    {
        MyDelegate del = new MyDelegate(PrintMessage);
        del("Hello, world!");
    }

    static void PrintMessage(string message)
    {
        Console.WriteLine(message);
    }
}

  9. What is an Anonymous Type in C#?

    Anonymous types allow you to create objects without having to explicitly define a type beforehand. The compiler automatically generates a class with read-only properties for each property specified in the object initializer.

    Example:

    csharp
    var person = new { Name = "John", Age = 30 };
Console.WriteLine(person.Name + ", " + person.Age);

  10. What is Boxing and Unboxing in C#?

    Boxing is the process of converting a value type to the type object or to any interface type implemented by this value type. Unboxing is the opposite process.

    Example:

    csharp
    int i = 10;
object obj = i; // Boxing
int j = (int)obj; // Unboxing

  11. What is the difference between IEnumerable and IQueryable in LINQ?

    IEnumerable represents a forward-only cursor of elements, making it suitable for querying data in-memory. IQueryable represents a query that can be executed against a specific data source, such as a database.

  12. What is the use of the "using" statement in C#?

    The using statement is used to ensure that a resource is disposed of properly after it is no longer needed, by automatically calling the Dispose method.

    Example:

    csharp

{
    string line = stream.ReadLine();
    Console.WriteLine(line);
} // The stream will be automatically disposed of after this block

  14. What are Extension Methods in C#?

    Extension methods allow you to add new methods to existing types without modifying them, making it useful for adding functionality to classes that you don't have control over.

    Example:

    csharp

  18. What is the purpose of the "base" keyword in C#?

    The base keyword is used to access members of the base class from within a derived class.

    Example:

    csharp
    public class MyBaseClass
{
    public void MyMethod()
    {
        Console.WriteLine("Base class method");
    }
}

public class MyDerivedClass : MyBaseClass
{
    public void MyMethod()
    {
        base.MyMethod(); // Calls the base class method
        Console.WriteLine("Derived class method");
    }
}

  19. What is Method Overriding in C#?

    Method overriding allows a subclass to provide a specific implementation of a method that is already provided by its superclass.

    Example:

    csharp
    public class Animal
{
    public virtual void MakeSound()
    {
        Console.WriteLine("Animal makes a sound");
    }
}

public class Dog : Animal
{
    public override void MakeSound()
    {
        Console.WriteLine("Dog barks");
    }
}

  32. What is Dependency Injection (DI) in C#?

    Dependency Injection is a design pattern in which a class receives its dependencies from external sources rather than creating them itself. It helps in achieving loose coupling and better testability.

    Example:

    csharp
    public class MyClass
{
    private readonly IService _service;

    public MyClass(IService service)
    {
        _service = service;
    }

    public void DoSomething()
    {
        _service.PerformOperation();
    }
}
