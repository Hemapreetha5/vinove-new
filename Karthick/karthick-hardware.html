1. 1) What is a Computer System?

    A computer system consists of hardware and software working together to process data into information.
    Hardware is the physical part (CPU, RAM, storage), and software is the set of instructions that tells the hardware what to do.
    Input devices feed data to the computer; output devices display results.
    A system bus connects all components for communication.
    It forms the backbone of all computing tasks.

    
                      
     INPUT → CPU ↔ MEMORY → OUTPUT
           │
         STORAGE

    2) Define CPU and its Functions

    CPU (Central Processing Unit) is the “brain” of the computer.
    It executes instructions from programs by fetching, decoding, and executing them.
    It consists of the ALU (Arithmetic Logic Unit), Control Unit, and registers.
    The ALU performs arithmetic and logical operations.
    The Control Unit manages data flow and instruction sequencing.

    

     CPU
 ┌──────┐
 │ ALU  │
 │ CU   │
 │ REGs │
 └──────┘

    3) What is Motherboard?

    The motherboard is the main circuit board that connects all components.
    It houses the CPU socket, RAM slots, expansion slots, and power connectors.
    It includes buses and chipsets for communication between devices.
    BIOS/UEFI firmware resides on a chip here.
    Essentially, it’s the central hub of hardware interaction.

    

     ┌────────────────────────────┐
 │ CPU  RAM  PCIe  BIOS Chip  │
 │      Slots     Slots       │
 └────────────────────────────┘

    5) What is Cache Memory?

    Cache is a small, high‑speed memory between CPU and RAM.
    It stores frequently used data to reduce access time.
    Levels: L1 (fastest, smallest), L2, L3 (larger, slower).
    It greatly improves performance by avoiding waiting for RAM.
    It works on the principle of locality of reference.

    CPU ↔ L1 ↔ L2 ↔ RAM ↔ HDD/SSD

    6) Define BIOS and UEFI

    BIOS (Basic Input Output System) initializes hardware during boot.
    UEFI is the modern replacement with GUI and security features.
    BIOS uses MBR partitioning; UEFI uses GPT.
    UEFI supports faster booting and larger drives.
    Both load the OS bootloader.

    Power ON → UEFI/BIOS → Bootloader → OS

    7) What are Buses in Computers?

    A bus is a communication pathway for data transfer inside the system.
    Three main buses: Data Bus (data), Address Bus (location), Control Bus (signals).
    Wider buses transfer more data (e.g., 64‑bit vs 32‑bit).
    They connect CPU, memory, and I/O devices.
    They determine the speed and efficiency of data flow.

    CPU ⇄ Data Bus ⇄ Memory

    9) What is a Power Supply Unit (PSU)?

    PSU converts AC from mains to DC voltages for computer parts.
    It supplies multiple voltages like +12V, +5V, +3.3V.
    Efficiency ratings (80+, Gold/Platinum) indicate power conversion quality.
    It protects components from voltage fluctuations.
    Power connectors go to motherboard, CPU, drives, GPU.

    AC Mains → PSU → Motherboard/Drives/GPU

    10) Explain GPU

    GPU (Graphics Processing Unit) accelerates graphics tasks.
    It has many cores optimized for parallel processing.
    Used for gaming, video rendering, machine learning.
    Can be integrated (on CPU) or discrete (separate card).
    More VRAM improves texture and compute performance.

    CPU ↔ GPU → Display

    11) What is an I/O Device?

    I/O (Input/Output) devices allow data exchange between user and system.
    Input examples: Keyboard, Mouse, Scanner.
    Output examples: Monitor, Printer, Speakers.
    Some are combo I/O (e.g., Touchscreen).
    They connect via USB, Bluetooth, etc.

    Human ⇄ I/O Device ⇄ Computer

    12) Define Clock Speed

    Clock speed is the number of cycles a CPU can execute per second.
    Measured in GHz (billion cycles per second).
    Higher speed means faster instruction execution.
    However, architecture and core count also impact performance.
    It’s like the heartbeat of the processor.

    13) What is Virtual Memory?

    Virtual memory uses storage (HDD/SSD) to extend RAM.
    It swaps inactive pages to disk when RAM is full.
    This prevents crashes when many programs run.
    It’s slower than RAM but increases capacity.
    Managed by the OS.

    RAM ←→ Pagefile/Swap (Disk)

    14) Explain Expansion Slots

    Expansion slots on motherboard allow additional cards (GPU, NIC).
    Common standards: PCIe x16, x4, x1, etc.
    More lanes = more bandwidth.
    They increase system capabilities without soldering.
    Hot‑plug depends on hardware support.

    15) What is Chipset?

    Chipset manages data flow between CPU, memory, and peripherals.
    Consists of Northbridge and Southbridge (older systems).
    Modern systems use a Platform Controller Hub (PCH).
    It determines feature support (USB, SATA, PCIe).
    It impacts upgrade compatibility.

    16) What is RAID?

    RAID (Redundant Array of Independent Disks) combines multiple drives.
    Improves performance or fault tolerance depending on level.
    RAID 0 = striping (speed), no redundancy.
    RAID 1 = mirroring (redundancy), slower write.
    Advanced levels mix both.

    17) What is Overclocking?

    Overclocking runs a component above its rated speed.
    Common on CPUs and GPUs for performance gains.
    Requires better cooling to avoid overheating.
    Can shorten hardware life if unstable.
    Done via BIOS/UEFI settings.

    18) What is Form Factor?

    Form factor defines motherboard and case size/layout.
    Examples: ATX, Micro‑ATX, Mini‑ITX.
    Affects number of slots and ports.
    Ensures compatibility of PSU and components.
    Smaller form factors fit compact builds.

    19) Explain Thermal Paste

    Thermal paste fills microscopic gaps between CPU and heatsink.
    It improves heat conduction from chip to cooler.
    Applied as a thin layer on CPU top.
    Helps prevent thermal throttling.
    Needs replacement when removed.

    20) What is Antivirus Hardware?

    Hardware firewalls and intrusion devices filter malicious traffic.
    They protect the system/network at hardware level.
    Examples: Routers with built‑in firewall.
    Faster than software-only solutions.
    Important for network security.

    21) What are Registers in CPU?

    Registers are tiny, super‑fast storage inside CPU.
    Store intermediate data and instructions.
    Examples: PC (Program Counter), ACC (Accumulator).
    They enable quick access without memory latency.
    Fundamental for instruction execution.

    22) What is an Interrupt?

    An interrupt signals the CPU to stop current work and handle urgent task.
    Generated by hardware or software.
    Examples: Keyboard input, timer.
    After handling, CPU resumes previous task.
    Improves multitasking.

    23) What is DMA?

    DMA (Direct Memory Access) lets devices transfer data without CPU.
    It speeds up I/O operations.
    DMA controller manages addresses and transfer size.
    CPU sets parameters and continues other tasks.
    Used in disk and network controllers.

    24) What is POST?

    POST (Power‑On Self Test) checks hardware at boot.
    Verifies CPU, RAM, GPU, keyboard, etc.
    Errors are indicated by beeps or screen messages.
    Passed POST loads bootloader.
    Essential for system stability check.

    25) What is SCSI?

    SCSI (Small Computer System Interface) connects high‑speed devices.
    Common in servers and storage arrays.
    Supports multiple devices on one bus.
    Faster and more robust than older interfaces.
    Has complex commands for data handling.

    26) What is USB?

    USB (Universal Serial Bus) is a standard for connecting peripherals.
    Supports data transfer and power supply.
    Versions: USB 2.0 (480 Mbps), USB 3.0 (5 Gbps), USB 4.0 (40 Gbps).
    Connectors: Type-A, Type-B, Type-C.
    Hot-swappable, easy to connect/disconnect devices.

    Computer ↔ USB Port ↔ Mouse/Keyboard/Storage

    28) What is HDMI?

    HDMI (High-Definition Multimedia Interface) transmits video and audio digitally.
    Supports high resolutions (up to 8K) and surround sound.
    Replaced analog VGA and DVI in modern systems.
    Uses a single cable for both video/audio.
    Common in TVs, monitors, and projectors.

    Computer/Console → HDMI → Monitor/TV

    29) What is Ethernet?

    Ethernet is a wired networking technology using twisted-pair cables.
    Speeds: 10 Mbps, 100 Mbps (Fast), 1 Gbps (Gigabit), 10 Gbps.
    Uses MAC addressing for data transfer.
    Provides stable, low-latency network connections.
    Widely used in LAN environments.

    Computer ↔ Switch/Router ↔ Network

    31) What is CMOS Battery?

    CMOS battery powers BIOS/UEFI memory when the system is off.
    Maintains system date, time, and settings.
    Usually a CR2032 coin cell.
    Low battery can reset BIOS to default.
    Replacements are simple to install.

    Motherboard → CMOS Battery → BIOS Settings

    32) What is a Heat Sink?

    A heat sink dissipates heat from components like CPU/GPU.
    Made of metal (aluminum/copper) with fins for more surface area.
    Works with thermal paste to improve conduction.
    Can be passive (no fan) or active (with fan).
    Prevents overheating and thermal throttling.

    CPU
Heat Sink (fins)
Fan (optional)

    33) What is a Network Interface Card (NIC)?

    NIC allows a computer to connect to a network.
    Can be wired (Ethernet) or wireless (Wi-Fi).
    Contains a MAC address for device identification.
    Supports speeds like 1 Gbps or 10 Gbps.
    Essential for LAN and Internet access.

    34) What is PSU Efficiency?

    Efficiency = (Power Output ÷ Power Input) × 100%.
    High efficiency reduces heat and electricity usage.
    Rated as 80+, Bronze, Silver, Gold, Platinum, Titanium.
    Better efficiency = less energy wasted.
    Important for high-power systems and servers.

    35) What is POST Beep Code?

    POST beeps indicate hardware issues during boot.
    Different beep patterns signal RAM, GPU, or CPU errors.
    Useful for diagnosing system problems without display.
    Varies by BIOS manufacturer (AMI, Phoenix, Award).
    Can save troubleshooting time.

    36) What is ECC RAM?

    ECC (Error-Correcting Code) RAM detects and corrects memory errors.
    Used in servers and critical systems.
    Prevents data corruption and system crashes.
    Slower and more expensive than standard RAM.
    Supports single-bit error correction.

    38) What is Thunderbolt?

    Thunderbolt is a high-speed interface using USB-C connectors.
    Supports data, video, and power over a single cable.
    Speeds: Thunderbolt 4 up to 40 Gbps.
    Can daisy-chain multiple devices.
    Common in high-end laptops and external storage.

    39) What is SODIMM vs DIMM?

    Feature DIMM SODIMM

    Pins 240 pins (DDR3) 204 pins (DDR3)
    Use Desktop PCs Laptops/Small Devices
    Voltage Standard Low voltage
    Upgrade Easy in desktops Laptop-dependent

    40) What is SATA?

    SATA (Serial ATA) connects storage drives to the motherboard.
    Supports hot-swapping, faster than old PATA interface.
    Versions: SATA I (1.5 Gbps), II (3 Gbps), III (6 Gbps).
    Used for HDDs, SSDs, and optical drives.
    Cable: thin, flexible ribbon.

    41) What is DisplayPort?

    DisplayPort transmits digital video and audio.
    Supports high resolutions (4K, 8K) and refresh rates.
    Can carry multiple monitors via daisy chaining.
    More flexible than HDMI for monitors.
    Supports adaptive sync technologies like FreeSync.

    42) What is a Bus Width?

    Bus width = number of bits transferred in parallel.
    Wider bus = more data per cycle = faster.
    Examples: 32-bit, 64-bit.
    Common in memory and CPU communication.
    Determines throughput of the system.

    CPU ⇄ 64-bit Data Bus ⇄ RAM

    43) What is a Modem?

    Modem (Modulator-Demodulator) converts digital signals to analog for transmission.
    Used in DSL, cable, or fiber networks.
    Enables Internet access over telephone/fiber lines.
    Can be external or internal.
    Often combined with a router in one device.

    44) What is Firmware?

    Firmware is software embedded in hardware devices.
    Controls device behavior and hardware initialization.
    Found in BIOS, SSDs, printers, cameras.
    Can be updated (flashed) for improvements/fixes.
    Acts as the bridge between hardware and software.

    45) What is a GPU VRAM?

    VRAM (Video RAM) is memory on GPU for graphics data.
    Stores textures, frame buffers, shaders.
    Higher VRAM improves rendering at high resolution.
    Types: GDDR5, GDDR6, HBM2.
    Faster than system RAM for graphics operations.

    46) What is a CPU Socket?

    CPU socket is the physical interface for processor installation.
    Different sockets support different CPU generations.
    E.g., Intel LGA 1700, AMD AM4.
    Includes pins or pads for electrical contacts.
    Ensures proper CPU alignment and compatibility.

    Motherboard Socket ↔ CPU

    47) What is a Fan Controller?

    Fan controller regulates fan speed based on temperature.
    Improves cooling efficiency and reduces noise.
    Can be hardware (manual knob) or software-based.
    Works with CPU, GPU, and chassis fans.
    Important for overclocked systems.

    48) What is Optical Drive?

    Optical drives read/write CDs, DVDs, or Blu-rays.
    Uses laser to read disc data.
    Declining in use due to USB and streaming.
    Can be internal or external via USB.
    Used for software installation or media playback.

    49) What is a Tape Drive?

    Tape drives store large data backups on magnetic tape.
    Used in enterprise for archival storage.
    Sequential access, slower than disks.
    Very cost-effective for huge datasets.
    Supports long-term retention and reliability.
