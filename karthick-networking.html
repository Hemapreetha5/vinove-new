1. 1️⃣ What is Computer Networking?

    Answer:

    • Computer networking is the process of connecting two or more devices to share data and resources.

    • Devices can include computers, servers, printers, routers, and switches.

    • Networking helps in data communication, resource sharing, and collaboration.

    • Networks can be small (LAN) or large (WAN).

    • It uses wired (Ethernet) or wireless (Wi-Fi) media.

    • Protocols like TCP/IP control communication rules.

    • Networking improves efficiency and reduces cost.

    2️⃣ What are the types of networks?

    Answer:

    • LAN (Local Area Network): Covers small areas like home or office.

    • MAN (Metropolitan Area Network): Covers a city.

    • WAN (Wide Area Network): Covers countries or continents.

    • PAN (Personal Area Network): Very small range (Bluetooth).

    • CAN (Campus Area Network): Used in colleges or companies.

    • WAN uses public networks like the Internet.

    • LAN is faster and more secure than WAN.

    3️⃣ What is LAN?

    Answer:

    • LAN connects devices within a limited area.

    • It is commonly used in homes, offices, and schools.

    • LAN provides high speed and low latency.

    • Uses Ethernet cables or Wi-Fi.

    • Controlled by a single organization.

    • Examples: Office network, home Wi-Fi.

    • Cheaper and more secure than WAN.

    4️⃣ What is WAN?

    Answer:

    • WAN connects networks over long distances.

    • Internet is the best example of WAN.

    • WAN uses leased lines, satellites, or fiber optics.

    • Slower than LAN due to distance.

    • Managed by telecom providers.

    • Used by multinational companies.

    • More expensive and complex.

    5️⃣ What is a Network Topology?

    Answer:

    • Topology is the physical or logical arrangement of network devices.

    • It defines how devices are connected.

    • Helps in understanding network design.

    • Affects performance and fault tolerance.

    • Can be physical or logical.

    • Common topologies: Bus, Star, Ring, Mesh.

    • Important for troubleshooting.

    6️⃣ Types of Network Topology

    Answer:

    • Bus: Single cable connects all devices.

    • Star: All devices connect to a central switch.

    • Ring: Devices connected in circular form.

    • Mesh: Every device connects to every other.

    • Hybrid: Combination of topologies.

    • Star is most commonly used.

    • Mesh provides high reliability.

    8️⃣ What is the OSI Model?

    Answer:

    • OSI stands for Open Systems Interconnection.

    • It is a 7-layer reference model.

    • Helps understand network communication.

    • Each layer has specific responsibilities.

    • Developed by ISO.

    • Used for learning and troubleshooting.

    • Does not define protocols, only structure.

    9️⃣ What are the 7 layers of OSI Model?

    Mnemonic: A P S T N D P
    (All People Seem To Need Data Processing)

    Layer No Layer Name
    7 Application
    6 Presentation
    5 Session
    4 Transport
    3 Network
    2 Data Link
    1 Physical

    🔹 OSI Layers Explanation (IMPORTANT)

    🔟 Physical Layer (Layer 1)

    Answer:

    • Handles physical transmission of data.

    • Deals with cables, connectors, voltages.

    • Transfers raw bits (0s and 1s).

    • Defines data rate and transmission mode.

    • No error detection.

    • Examples: Ethernet cable, fiber optic.

    • Devices: Hub, repeater.

    1️⃣1️⃣ Data Link Layer (Layer 2)

    Answer:

    • Responsible for node-to-node delivery.

    • Uses MAC addresses.

    • Performs error detection.

    • Divided into LLC and MAC sublayers.

    • Frames data.

    • Controls access to the medium.

    • Devices: Switch, Bridge.

    1️⃣2️⃣ Network Layer (Layer 3)

    Answer:

    • Responsible for logical addressing.

    • Uses IP addresses.

    • Performs routing and path selection.

    • Packet forwarding happens here.

    • Handles congestion control.

    • Routers operate at this layer.

    • Protocols: IP, ICMP, ARP.

    1️⃣3️⃣ Transport Layer (Layer 4)

    Answer:

    • Provides end-to-end communication.

    • Responsible for reliability.

    • Performs segmentation and reassembly.

    • Uses port numbers.

    • Flow and error control.

    • Protocols: TCP, UDP.

    • Ensures correct data delivery.

    1️⃣4️⃣ Session Layer (Layer 5)

    Answer:

    • Manages sessions between devices.

    • Establishes, maintains, terminates sessions.

    • Handles synchronization.

    • Controls dialog (half/full duplex).

    • Helps in session recovery.

    • Rarely implemented separately.

    • Example: NetBIOS session service.

    1️⃣5️⃣ Presentation Layer (Layer 6)

    Answer:

    • Responsible for data formatting.

    • Handles encryption and decryption.

    • Performs compression.

    • Converts data formats.

    • Makes data readable for application.

    • Ensures compatibility.

    • Example: SSL/TLS.

    1️⃣6️⃣ Application Layer (Layer 7)

    Answer:

    • Closest to the user.

    • Provides network services to applications.

    • Handles user interface.

    • Supports file transfer, email, browsing.

    • No actual application runs here.

    • Protocols: HTTP, FTP, SMTP, DNS.

    • Used directly by end users.

    1️⃣8️⃣ What is TCP/IP Model?

    Answer:

    • TCP/IP is a practical networking model.

    • Used on the Internet.

    • Has 4 layers.

    • Combines OSI layers.

    • Developed by DARPA.

    • Reliable and scalable.

    • Backbone of modern networking.

    2️⃣0️⃣ What is a Protocol?

    Answer:

    • Protocol is a set of rules.

    • Defines how data is transmitted.

    • Ensures proper communication.

    • Includes syntax, semantics, timing.

    • Standardizes communication.

    • Prevents data loss.

    • Examples: HTTP, FTP, TCP, IP.

    2️⃣1️⃣ What is TCP?

    Answer:

    • TCP stands for Transmission Control Protocol.

    • It is a connection-oriented protocol.

    • Ensures reliable data delivery.

    • Uses acknowledgements and retransmission.

    • Maintains sequence of packets.

    • Performs flow and congestion control.

    • Used in web, email, file transfer.

    2️⃣2️⃣ What is UDP?

    Answer:

    • UDP stands for User Datagram Protocol.

    • It is connectionless.

    • Does not guarantee delivery.

    • Faster than TCP.

    • No acknowledgements.

    • Used in streaming, gaming, VoIP.

    • Low overhead protocol.

    2️⃣3️⃣ Difference between TCP and UDP

    Feature TCP UDP
    Connection Connection-oriented Connectionless
    Reliability Reliable Unreliable
    Speed Slower Faster
    Error Checking Yes Basic
    Flow Control Yes No
    Use Case Web, Email Video, Games

    2️⃣4️⃣ What is a Port Number?

    Answer:

    • Port identifies a specific process.

    • Works with IP address.

    • Range: 0 to 65535.

    • Helps in multiplexing.

    • Used by Transport Layer.

    • Identifies application service.

    • Example: HTTP uses port 80.

    2️⃣5️⃣ Types of Ports

    Port Range Type
    0 – 1023 Well-known
    1024 – 49151 Registered
    49152 – 65535 Dynamic/Private

    2️⃣6️⃣ What is an IP Address?

    Answer:

    • IP stands for Internet Protocol.

    • Unique identifier for devices.

    • Works at Network Layer.

    • Enables logical addressing.

    • Two types: IPv4 and IPv6.

    • Needed for routing.

    • Example: 192.168.1.1

    2️⃣7️⃣ What is IPv4?

    Answer:

    • 32-bit address.

    • Written in dotted decimal.

    • 4 octets.

    • Total addresses ~4.3 billion.

    • Uses classes.

    • Supports subnetting.

    • Example: 10.0.0.1

    2️⃣8️⃣ What is IPv6?

    Answer:

    • 128-bit address.

    • Written in hexadecimal.

    • Large address space.

    • No need NAT.

    • Supports auto-configuration.

    • More secure.

    • Example: 2001:db8::1

    2️⃣9️⃣ Difference between IPv4 and IPv6

    Address Size 32-bit 128-bit
    Format Decimal Hexadecimal
    NAT Needed Yes No
    Security Optional Built-in
    Broadcast Yes No
    Address Count Limited Huge

    3️⃣0️⃣ What is Subnet?

    Answer:

    • Subnet divides network.

    • Improves performance.

    • Reduces broadcast.

    • Better security.

    • Uses subnet mask.

    • Helps in IP management.

    • Example: 255.255.255.0

    3️⃣1️⃣ What is Subnet Mask?

    Answer:

    • Defines network & host part.

    • 32-bit number.

    • Works with IP.

    • Uses 1s for network.

    • 0s for host.

    • Helps routing.

    • Example: /24

    3️⃣2️⃣ What is CIDR?

    Answer:

    • Classless Inter-Domain Routing.

    • Uses / notation.

    • Replaces classful.

    • Efficient IP usage.

    • Flexible subnetting.

    • Example: 192.168.1.0/24

    • Reduces wastage.

    3️⃣3️⃣ What is a Private IP?

    Answer:

    • Used inside networks.

    • Not routable on Internet.

    • Saves public IPs.

    • Defined by RFC1918.

    • Three ranges exist.

    • Example: 192.168.x.x

    • Used with NAT.

    Answer:

    • Globally unique.

    • Internet routable.

    • Assigned by ISP.

    • Used for websites.

    • Reachable from anywhere.

    • Not reusable.

    • Example: 8.8.8.8

    3️⃣6️⃣ What is NAT?

    Answer:

    • Network Address Translation.

    • Converts private to public IP.

    • Saves IP addresses.

    • Increases security.

    • Happens on router.

    • Types: Static, Dynamic, PAT.

    • Used in homes/offices.

    • Reduces admin work.

    4️⃣1️⃣ What is a Hub?

    Answer:

    • Hub works at Physical Layer.

    • Broadcasts data to all ports.

    • No intelligence.

    • Half-duplex.

    • Causes collisions.

    • Slower device.

    • Rarely used now.

    4️⃣2️⃣ What is a Switch?

    Answer:

    • Works at Data Link Layer.

    • Uses MAC addresses.

    • Sends data only to destination.

    • Full-duplex.

    • Faster than hub.

    • Reduces collision.

    • Used in LAN.

    4️⃣3️⃣ What is a Router?

    Answer:

    • Works at Network Layer.

    • Uses IP addresses.

    • Connects different networks.

    • Performs routing.

    • Breaks broadcast domains.

    • Supports NAT.

    • Used for Internet.

    4️⃣5️⃣ What is a MAC Address?

    Answer:

    • Media Access Control.

    • 48-bit address.

    • Physical address.

    • Unique per device.

    • Used in LAN.

    • Burned into NIC.

    • Example: 00:1A:2B:3C:4D:5E

    4️⃣6️⃣ What is ARP?

    Answer:

    • Address Resolution Protocol.

    • Converts IP to MAC.

    • Works in LAN.

    • Used by routers & hosts.

    • Uses broadcast request.

    • Cache stores mappings.

    • Example: Who has 192.168.1.1?

    4️⃣7️⃣ ARP Process

    Answer:

    • Device sends ARP request.

    • Broadcasts to network.

    • Destination replies with MAC.

    • Sender stores in ARP cache.

    • Reduces repeated ARP.

    • Used before sending packet.

    4️⃣8️⃣ What is ICMP?

    Answer:

    • Internet Control Message Protocol.

    • Used for error messages.

    • Works with IP.

    • Used in ping.

    • Reports unreachable hosts.

    • Diagnostic protocol.

    • No data transfer.

    4️⃣9️⃣ What is Ping?

    Answer:

    • Uses ICMP.

    • Tests connectivity.

    • Measures latency.

    • Checks host reachability.

    • Sends echo request.

    • Gets echo reply.

    • Used for troubleshooting.

    5️⃣0️⃣ What is Traceroute?

    Answer:

    • Traces path to destination.

    • Shows each hop.

    • Uses TTL.

    • Identifies delays.

    • Helps troubleshooting.

    • Finds broken links.

    • Uses ICMP/UDP.

    • Logical segmentation.

    • Breaks broadcast domain.

    • Improves security.

    5️⃣3️⃣ What is Trunk Port?

    Answer:

    • Carries multiple VLANs.

    • Used between switches.

    • Uses 802.1Q tagging.

    • Sends tagged frames.

    • Supports many VLANs.

    • Not access port.

    • Used in inter-switch links.

    5️⃣4️⃣ What is Access Port?

    Answer:

    • Carries one VLAN.

    • Used for end devices.

    • Sends untagged frames.

    • Assigns device to VLAN.

    • Simple port.

    • Common in LAN.

    • Example: PC port.

    • Each VLAN is separate.

    5️⃣8️⃣ What is a Broadcast Domain?

    Answer:

    • Area of broadcast reach.

    • All devices receive broadcast.

    • VLANs divide it.

    • Routers block it.

    • Too big = slow.

    • Design carefully.

    • Improves performance.

    5️⃣9️⃣ What is a Collision Domain?

    Answer:

    • Area where collision occurs.

    • Hubs create one domain.

    • Switch ports = one domain.

    • Collisions reduce speed.

    • Full duplex avoids collision.

    • Old networks issue.

    • Uses metrics.

    • Static or dynamic.

    • Enables internetwork communication.

    • No automatic updates.

    • Used in small networks.

    • Low CPU usage.

    Answer:

    • Automatically learns routes.

    • Uses protocols.

    • Updates automatically.

    • Scalable.

    • Adapts to changes.

    • More overhead.

    • Used in large networks.

    6️⃣5️⃣ What is a Routing Protocol?

    Answer:

    • Defines how routers share info.

    • Discovers routes.

    • Maintains routing table.

    • Determines best path.

    • Uses metrics.

    • Enables dynamic routing.

    • Examples: RIP, OSPF, EIGRP, BGP.

    6️⃣6️⃣ What is RIP?

    Answer:

    • Routing Information Protocol.

    • Distance vector.

    • Uses hop count.

    • Max 15 hops.

    • Slow convergence.

    • Uses UDP port 520.

    • Obsolete now.

    6️⃣7️⃣ What is OSPF?

    Answer:

    • Open Shortest Path First.

    • Link-state protocol.

    • Uses Dijkstra algorithm.

    • Fast convergence.

    • Uses areas.

    • Scalable.

    • Uses IP protocol 89.

    6️⃣8️⃣ What is EIGRP?

    Answer:

    • Enhanced Interior Gateway Routing Protocol.

    • Cisco proprietary.

    • Uses DUAL algorithm.

    • Fast convergence.

    • Supports VLSM.

    • Low bandwidth usage.

    • Hybrid protocol.

    6️⃣9️⃣ What is BGP?

    Answer:

    • Border Gateway Protocol.

    • Exterior gateway protocol.

    • Used between ISPs.

    • Path vector protocol.

    • Controls Internet routing.

    • Uses TCP port 179.

    • Highly scalable.

    Answer:

    • Time routers take to agree.

    • After network change.

    • Important for stability.

    • Faster is better.

    • OSPF/EIGRP converge fast.

    • RIP is slow.

    • Affects downtime.

    7️⃣2️⃣ What is Metric?

    Answer:

    • Value used to choose best route.

    • Lower metric = better path.

    • Different protocols use different metrics.

    • RIP uses hop count.

    • OSPF uses cost.

    • EIGRP uses composite.

    • BGP uses attributes.

    7️⃣3️⃣ What is Administrative Distance?

    Answer:

    • Trust value of route source.

    • Lower AD = more trusted.

    • Used when multiple routes exist.

    • Static AD = 1.

    • OSPF = 110.

    • RIP = 120.

    • BGP external = 20.
